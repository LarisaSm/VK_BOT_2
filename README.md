# VK-бот «Мастер-Ломастер»

VK-бот сообщества ВКонтакте «Мастер-Ломастер»: каталог услуг домашнего мастера, примерные цены, контакты и приём заявок на вызов мастера.

## О проекте

Бот разработан на **Python 3.11+** с использованием библиотеки **vkbottle** и **VK Long Poll API**. Реализованы главное меню, разделы услуг, прайс, контакты, раздел «О нас» и пошаговая форма заявки с сохранением в `requests.json`.

## Требования

- Python 3.11+
- Сообщество ВКонтакте с включёнными сообщениями и доступом к Long Poll API

## Получение кода

Склонируйте репозиторий и перейдите в папку с ботом — все следующие команды выполняются из неё:

```bash
git clone https://github.com/LarisaSm/VK_BOT_2.git
cd VK_BOT_2/master_lomaster_bot
```

## Создание виртуального окружения

### Windows

```bash
python -m venv .venv
.venv\Scripts\activate
```

### macOS/Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
```

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Настройка

1. Скопируйте `.env.example` в `.env`:

```bash
# macOS/Linux
cp .env.example .env

# Windows
copy .env.example .env
```

2. Откройте `.env` и добавьте токен сообщества:

```env
VK_TOKEN=ваш_токен_сообщества
MASTER_PHONE=+79990000000
```

Файл `.env` добавлен в `.gitignore` — не коммитьте его.

## Настройка сообщества VK

1. Создайте или откройте сообщество ВКонтакте.
2. **Настройки → Сообщения** — включите «Сообщения сообщества».
3. **Настройки → Работа с API → Ключи доступа** — создайте ключ с правом «Доступ к сообщениям» и скопируйте его в `VK_TOKEN`.
4. **Настройки → Работа с API → Long Poll API** — включите Long Poll API.
5. На вкладке «Типы событий» включите событие «Входящие сообщения».
6. Сохраните изменения.

## Запуск

Из каталога `master_lomaster_bot/`:

```bash
python main.py
```

После запуска в консоли появится сообщение о подключении к VK Long Poll API.

## Реализованные функции

- Главное меню: Услуги, Прайс, Оставить заявку, Контакты, О нас.
- Категории услуг: сантехника, электрика, мебель, мелкий ремонт, установка и крепление.
- Прайс с минимальной стоимостью выезда.
- Пошаговая заявка: задача → имя → телефон → время.
- Простая проверка телефона (варианты +7/8, с пробелами и дефисами).
- Отмена заявки командой «Отмена» или кнопкой «❌ Отмена».
- Сохранение заявок в `requests.json` без удаления существующих.
- Навигация: «⬅ Назад / К услугам», «🏠 Главное меню».
- Текстовые команды: Начать, Старт, Меню, menu, start.
- Обработка неизвестных сообщений с возвратом в меню.
- Логирование запуска, создания заявки (с VK ID) и ошибок.
- Токен хранится только в `.env`.
